# Dock 数字快捷键

这是一个免费的原生 macOS 菜单栏程序，用全局快捷键控制 Dock 中的应用。

程序会自动读取当前 Dock 的应用顺序：

- `Option + 1`：访达
- `Option + 2` 及之后：按 Dock 中的应用顺序对应
- 最多支持到 `Option + 9`

单窗口应用的行为是：第一次按下打开，第二次按下隐藏。

多窗口应用的行为是：第一次按下只显示第一个窗口，第二次只显示第二个窗口，依次循环切换；其他窗口保持打开但会最小化，不会关闭应用。切换到其他应用后再次按下，会从第一个窗口开始。

程序使用 macOS 辅助功能读取窗口列表。全局快捷键由 macOS 的 Carbon 快捷键服务处理，因此只需要在「系统设置 → 隐私与安全性 → 辅助功能」中允许本程序。
程序每 2 秒检查一次 Dock 顺序。你拖动 Dock 中的应用后，快捷键会自动更新。

## 编译

在终端进入这个目录并执行：

```sh
./build.sh
open DockNumberShortcut.app
```

`main.m` 是程序源码，`build.sh` 使用 macOS 自带的 Clang 编译。

首次使用时，到「系统设置 → 隐私与安全性 → 辅助功能」，允许“Dock 数字快捷键”。然后从菜单栏的 `⌥` 图标退出并重新打开程序。如果列表中有旧的同名项目，请删除后用当前路径重新添加。
